# Counter Application

A lightweight and interactive counter application developed using **HTML, CSS, and JavaScript**. This project demonstrates basic JavaScript functionality and DOM manipulation through a simple user interface.

## Overview

The application allows users to increase, decrease, or reset a numerical value using three buttons. The counter updates instantly based on user interactions.

## Key Features

- **Increase:** Adds 1 to the current counter value.
- **Decrease:** Subtracts 1 from the current counter value.
- **Reset:** Sets the counter back to 0.
- **Instant Updates:** Displays changes without refreshing the page.

## Technologies Used

- **HTML5** – Defines the application structure.
- **CSS3** – Handles styling and layout.
- **JavaScript** – Manages counter operations and user interactions.

## Getting Started

1. Download or clone the project repository.
2. Navigate to the project directory.
3. Open `index.html` in any modern web browser.
4. Click the buttons to control the counter.

## How It Works

The application uses JavaScript event handling to detect button clicks and update the displayed counter value dynamically.

No additional dependencies, installations, or server configurations are required.

## Purpose

This project was created to practice fundamental web development concepts, including DOM manipulation, event handling, and basic user interface design.
